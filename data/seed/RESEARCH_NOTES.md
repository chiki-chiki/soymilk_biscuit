# 豆乳ビスケット シード調査メモ（2026-10-16 時点）

## 1. 調査方法と重大な制約

- **この環境では Web ページ本文を直接取得できませんでした。** kaldi.co.jp、web.archive.org、news.yahoo.co.jp、news.allabout.co.jp、ameblo.jp、trilltrill.jp などはどれも、WebFetch／curl の段階で DNS エラーまたはプロキシ拒否（403）になりました。この環境のネットワークポリシーで許可されていないホストと思われます。
- そのため、**すべての値は Web 検索ツール（WebSearch）が返した「タイトル・URL・要約・抜粋引用」から拾ったもの**です。一次ページを開いて目で確かめた値は 1 件もありません。
  - 検索ツールの要約は自動生成で、抜粋の引用元が明示されないこともあります。実際、宇治抹茶の枚数を「7枚」とする回答と「9枚」とする回答が出るなど、揺れがありました。
  - CSV の `confirmed` は「検索結果の抜粋・要約で、情報源にそう書かれていると示されたもの」という意味です。**ページ本文で検証した `confirmed` ではありません。**
- 公式 X（@KALDI_webshop）の投稿日時は、ステータス ID（Snowflake）から算出しました（例: 1782605393279221944 → 2024-04-23 12:00 JST）。
- ameblo 記事の時期は、記事 ID の並び（例: 12730283794 がプリンの 2022 年 3 月頃、12960308207 が宇治抹茶の 2026 年 3 月頃）から推定しました。この方法で決めたものはすべて `estimated` とし、notes に記載しています。
- 実施した検索はおよそ 45 回です。対象は、フレーバー別・年別・アソート別、福袋、公式 X です。

## 3. 情報が矛盾していた点

3. **プレーンの価格推移**：198 円 → 247 円（All About）→ 302 円（公式オンラインストア）。JAL Mall は 347 円でした。改定日はいずれも不明です。

5. **すいか**：237 円（「新発売」記事）と 258 円の記事があります。初登場の年（2022 年か 2023 年か）は特定できませんでした。
6. **さくら**：216 円、235 円、278 円、321 円の記載があり、それぞれ何年の価格かは不確実です。
7. **紫いも／紅いも**：表記が揺れています（公式は「紫いもクリーム」）。
8. **クリスマスパック 2023 の中身**：「キャラメル＋アップルシナモン」（ブログ、公式ページの説明）と「メープル＋アップルシナモン」（オンラインストアのレビュー）で食い違いました。価格も 645 円と 753 円があり、どちらが何年の価格か不明です。

- プレーンの初登場時期：「2015 年 3 月」とする要約がありましたが、出典を特定できなかったため空欄です。
- ピーナッツ、ココナッツ、杏仁豆腐、レモン、いちご（初期）、ラムレーズンの販売年。2019〜2021 年頃に複数回出たとみられます。
- ピスタチオの初登場年。2024 年の公式 X に「今年も」とあるので、2024 年より前に出ていることは確かです。
- 2025 年のプリン、さくら、ミルクティー、紫いもの各販売期があったかどうか。
- 2025 年のハロウィンパックとクリスマスパックの年別の中身と価格。公式ページは 26p で 753 円ですが、年は不明です。
- 2024 年・2025 年のアソートパックとお正月パックの、味ごとの枚数。18÷3＝6 と推測できますが、推測は書かない方針なので空欄にしています。

## 6. データ設計上の判断

- 同じ商品の年ごとの販売を、別々の release 行にしています。年が特定できない公式ページの価格は `*-os` という行にまとめました。
- ウィンターバッグ（6 品入りの雑貨セット）はビスケットの詰め合わせではないため、アソートとして登録していません。中に入っている「オランジュショコラ」は単品の release（価格は空欄）として登録しました。
- 「ハロウィンパック メープルクリーム 18p」は味が 1 種類だけなので、メープルの単品 release として登録しました。
- アソートにしか入っていない味（塩バニラ、きなこ、バニラ、キャラメル、アップルシナモン、ホワイトチョコ、あまおういちご）と、ピーナッツ（要確認）には、flavors.csv の notes に「アソート限定」と書いています。
- 「2026年福袋の紅白パック」は、お正月パックとは名前が違うので別アソート（kohaku-pack）にしました。
